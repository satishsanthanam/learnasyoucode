🌙 Enable Dark Mode via Browser Flags

Force system-wide dark rendering on any website

🌐
Chrome / Edge / Brave
1
Go to chrome://flags (or edge://flags)
2
Search for "Auto Dark Mode for Web Contents"
3
Set dropdown to Enabled
4
Relaunch the browser when prompted
#enable-force-dark #enable-webui-dark-mode
🦊
Firefox
1
Go to about:config
2
Accept the risk warning prompt
3
Search: layout.css.prefers-color-scheme.content-override
4
Change value to 0 (dark)
5
Restart the browser
🧭
Safari (macOS)
1
Open System Settings → Appearance
2
Select Dark
3
Safari automatically adapts sites supporting prefers-color-scheme

⚠️ Things to Know

  • These flags force dark rendering on all sites — expect occasional bugs (inverted images, low contrast).
  • Different from a site's native dark mode toggle using CSS prefers-color-scheme.
  • Flags are experimental and may be renamed or removed in future updates.
  • To disable, revisit the flag/setting and reset to Default.
Compatible with latest Chromium (v100+), Firefox (v90+), and macOS Safari
